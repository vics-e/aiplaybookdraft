About this checklist

The tracker combines the supplied Manual Testing and QA Release checklists. A row is passed only when its full condition has supporting evidence. Checks that require a business decision, formal process evidence, unsupported browser, physical device, CMS access or release approval stay with Project or QA.

Changes made on this page save only in the current browser. Download the editable JSON backup and return it to the project owner or agent before expecting the official GitHub and Vercel version to change.
